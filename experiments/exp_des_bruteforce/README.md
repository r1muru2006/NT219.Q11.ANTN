# exp_des_bruteforce

This folder contains DES brute-force PoC scripts and instructions for Week 3-4.

## Files
- `bruteforce_des.py` — single-process demo that searches a reduced keyspace (2^16).
- `bruteforce_des_mp.py` — multiprocessing demo that splits a larger reduced keyspace across CPU cores.
- `demo_cipher.hex` — sample ciphertext (hex) for demo (generated by scripts).
- `README.md` — this file.

## Usage (safe lab environment)
1. Create and activate a virtualenv:
   ```
   python3 -m venv venv
   source venv/bin/activate
   pip install pycryptodome
   ```
2. Run the demo:
   ```
   python bruteforce_des.py
   ```
   For multiprocessing demo:
   ```
   python bruteforce_des_mp.py
   ```

## Important warnings
- These scripts are for educational use only. Do not attempt to use them against systems you don't own or have explicit permission to test.
- The scripts use a reduced keyspace for reproducibility. Do not change to full 2^56 keyspace on uncontrolled hardware.
